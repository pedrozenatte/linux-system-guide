#### Comandos úteis do tree: 
**Limitar profundidade**
```bash
tree -L 2
```
2 foi o nível de profundidade


**Mostrar arquivos ocultos**
```bash
tree -a
```

**Mostrar apenas diretórios**
```bash
tree -d
```

**Mostrar tamanho dos arquivos**
```bash
tree -h
```
